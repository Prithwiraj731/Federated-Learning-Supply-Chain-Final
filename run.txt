Control Tower:
python -m streamlit run app.py --server.address 0.0.0.0

Client Node 0 (Port 8502, Secure Port 8800):
$env:SC_CLIENT_ID="0"
$env:SC_NODE_PORT="8800"
python -m streamlit run client_app.py --server.port 8502 --server.address 0.0.0.0

Client Node 1 (Port 8503, Secure Port 8801):
$env:SC_CLIENT_ID="1"
$env:SC_NODE_PORT="8801"
python -m streamlit run client_app.py --server.port 8503 --server.address 0.0.0.0

Client Node 2 (Port 8504, Secure Port 8802):
$env:SC_CLIENT_ID="2"
$env:SC_NODE_PORT="8802"
python -m streamlit run client_app.py --server.port 8504 --server.address 0.0.0.0

📱 Mobile Access:
If your mobile phone is on the same Wi-Fi network, you can access the dashboards using your computer's local IP address.
For example, if your computer's IP is 192.168.1.5:
- Tower: http://192.168.1.5:8501
- Client 0: http://192.168.1.5:8502
- Client 1: http://192.168.1.5:8503
- Client 2: http://192.168.1.5:8504
